Cursor Cat Extension Test Page

How to Test

  1. Load the extension in Chrome (chrome://extensions, enable Developer Mode, Load Unpacked)
  2. Click the extension icon and enable the cat
  3. Move your cursor around this page to see the cat follow it
  4. Try hovering over the cat for 3+ seconds to see special animations
  5. Click on the cat to hear it meow and see a reaction animation

Expected Features

  • Cursor Following: Cat should follow your cursor position smoothly
  • Walking Animation: Cat uses walking animation when moving at normal speed
  • Running Animation: Cat runs faster when cursor moves quickly or is far away
  • Idle on Hover: Cat plays idle animation when cursor is on it
  • Special Animations: After 3 seconds of hovering, cat sleeps or waves paw
  • Click Reaction: Clicking the cat triggers meow sound + meow/scratch animation
  • Bowl Collection: Cat collects food bowls scattered on the page
  • Text Hole: Text parts around the cat creating a "hole" effect

The cat extension creates an interactive experience on any webpage. As you move your cursor around, you'll notice the adorable pixel cat following closely behind. The cat is smart enough to run when you move quickly, making the interaction feel more alive and responsive. Try different movements to see how the cat reacts!

Cursor-following mechanics in games and interactive applications create a sense of connection between the user and the digital elements on screen. By implementing velocity detection, we can make the cat appear more intelligent - it knows when to walk leisurely and when to sprint to catch up with your fast-moving cursor.

The text rendering system in this extension uses a simplified approach to create holes around the cat character. As the cat moves through paragraphs, the text appears to part around it, creating a unique visual effect that makes it seem like the cat is truly inhabiting the webpage rather than just being overlaid on top of it.

Food bowls are scattered across paragraphs on the page, giving the cat a purpose beyond just following your cursor. As the cat collects these bowls, your score increases, adding a gamification element to the experience. Bowls respawn after being collected, ensuring the fun never stops!

Testing Instructions

To fully test the extension, try moving your cursor to different areas of the page. Watch how the cat navigates around the text, creating holes as it moves. Try moving your cursor quickly from one side of the page to the other - the cat should switch to a running animation to catch up with you.

Test the hover behavior by placing your cursor over the cat and keeping it still. First, you'll see the idle animation. If you keep hovering for about 3 seconds, the cat should transition to either a sleeping animation or a paw-waving animation. This shows that the timing mechanics are working correctly.

The collision detection for bowls should be accurate. As the cat approaches a bowl, it should collect it when they overlap. The score counter in the top-left corner should increment, and you should hear a collection sound effect. After a few seconds, the bowl should respawn in a different location on the page.

Pay attention to the directional animations. The cat should face the direction it's moving - down, up, left, right, and the diagonal directions in between. The sprite sheet contains animations for all eight directions, and the code should select the appropriate animation based on the movement vector.

Finally, test the extension across different types of webpages - news sites, Wikipedia articles, blogs, and documentation pages. The paragraph detection should work on most standard web layouts, identifying suitable text blocks for the cat to interact with and for bowl placement.
